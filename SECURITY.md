# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it privately.

Please do **NOT** open a public issue for security vulnerabilities. Instead, contact the maintainers directly via email.

All security reports will be acknowledged within 48 hours, and a patch or mitigation will be developed as soon as possible.
